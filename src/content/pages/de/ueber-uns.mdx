import { siteConfig } from "~/config/site";
import { getCollection } from "astro:content";
import { getAllAuthors, visiblePosts } from "~/lib/posts";
import { t, getLocalePath } from "i18n:astro";

export const allPosts = visiblePosts(await getCollection("posts"));
export const authorEntries = await getCollection("authors");
export const authors = getAllAuthors(allPosts, authorEntries);

## Was hier veröffentlicht wird

Ausführliche Notizen zur Softwareentwicklung: die Entscheidung hinter einer Änderung, was sie gekostet hat und was beim nächsten Mal anders gemacht würde. Beiträge werden so geschrieben, dass man sie einmal liest, sorgfältig,而不是 überfliegt.

## Wie es geschrieben wird

Jeder Beitrag zielt darauf ab, reproduziert zu sein und ehrlich über Kompromisse zu sein. Wenn etwas nicht funktioniert hat, kommt das ebenfalls hinein. Korrekturen werden direkt vorgenommen, mit dem Aktualisierungsdatum oben im Beitrag.
